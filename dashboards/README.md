# Power BI Dashboard

This folder contains the Power BI dashboard and supporting screenshots for the Retail Data Engineering Platform.

## Contents

### powerbi/

Contains the Power BI project file:

- `Retail Sales Dashboard.pbix`

Open this file in Microsoft Power BI Desktop to explore the dashboard.

### screenshots/

Contains screenshots of the completed dashboard and project outputs used in the project documentation.

## Dashboard Features

- Total Revenue
- Total Orders
- Average Order Value
- Highest Order Value
- Lowest Order Value
- Price Category Distribution
- Batch-wise Processing Summary

The dashboard is built using the Gold layer data generated by the Airflow ETL pipeline and stored in MySQL.
